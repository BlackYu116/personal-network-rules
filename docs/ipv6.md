# IPv6：现状、规则就绪度与两条路线

家庭网络当前实际是 IPv4 单栈使用。本文说明现状、已核实的规则侧就绪度，以及两条路线——保持 IPv4（默认推荐）或"国内直连 v6 + 海外锁定 v4"。所有路由器/节点服务器的变更由用户本人执行；本文只做准备与核对说明。

## 现状（2026-09-27 只读审计）

- .22 旁路由：RA、DHCPv6、NDP 代理均关闭。
- OpenClash：IPv6 代理关闭、IPv6 DNS 解析关闭。
- Dnsmasq：过滤 AAAA 应答。
- 结果：客户端即使持有 IPv6 地址也拿不到 v6 目标地址，全部流量走 v4。海外出口 IP 稳定、无 v6 泄漏，与"稳定出口、控制风控"的目标一致。

## 规则侧就绪度（2026-09-28 已核实，无需改规则）

| 规则集 | v6 覆盖 | 作用 |
|---|---|---|
| private-ip | fc00::/7、fe80::/10 等4条 | 内网 v6 直连 |
| cn-ip | 3407条 v6 段，含移动 240e::、联通 2408::、电信 2001:: | 国内 v6 直连 |
| MATCH 兜底 | 天然覆盖 | 其余 v6 交海外默认 |

验证脚本的 `fc00::1 → DIRECT` 案例已覆盖内网 v6 匹配。**启用 IPv6 不需要改本仓库任何文件。**

## 先摸底（只读，不改任何设置）

1. 手机 Wi-Fi 详情 / 电脑 `ifconfig en0`：是否已有 `240e:`、`2408:` 等 2xxx 开头的全局 v6 地址。中国移动宽带通常直接下发。
2. 浏览器访问 test-ipv6.com：当前应显示无 IPv6（AAAA 被 Dnsmasq 过滤）。
3. 若已有 v6 地址但 test-ipv6 无 v6：说明 RA 来自主路由 .1，.22 只是没接管 v6。当前**不存在 v6 泄漏**（DNS 层已挡住），启用时也只需动 OpenClash 一侧。

## 路线A：保持 IPv4 单栈（默认推荐）

零改动、零风险。海外出口 IP 与现在完全一致，银行/AI/交易所看到的是同一个 v4 地址。国内直连少了 v6 属于可接受的代价——如果 v6 对你没有具体收益场景（某些国内服务 v6 更快、或需要 v6 直连的设备），选这条就是正确决定。

## 路线B：国内直连 v6 + 海外锁定 v4

收益：国内直连流量可用 v6（部分移动宽带 v6 质量更好、绕开 v4 NAT）；**海外路径完全不变**。

关键前提：海外出口必须先锁定 v4。否则节点远端解析可能返回 AAAA，出口变成节点的 v6 地址——服务商会看到一个新 IP，风控画像变化，与目标背道而驰。

按顺序执行（每步可独立回退）：

1. **锁 v4（先做，与客户端无关）**
   - DMIT 节点：Xray 出站 freedom 的 `domainStrategy` 设为 `UseIPv4`，节点远端解析永远选 v4。这是 VPS 变更，单独操作、单独验证。
   - 机场节点：多数出口仅 v4，无需处理；不放心可用 [exit-check](node-quality.md) 逐个确认出口是否出现 v6。
2. **客户端拿到 v6 地址**：若摸底发现客户端已有 v6（.1 在发 RA），跳过本步。否则在 .22 的 网络→接口→LAN 开启 RA（服务器模式）和 DHCPv6。注意只保留一个 RA 源，避免 .1 与 .22 同时宣告导致客户端网关漂移。
3. **OpenClash 开 v6**（插件设置）：「IPv6 代理」开启、「IPv6 DNS 解析」开启；关闭 Dnsmasq 的 AAAA 过滤。重启插件生效（短暂断网，选方便时间）。
4. **验证**：
   - CN 直连访问 test-ipv6.com → 显示运营商 v6（如 240e:...）。
   - 走代理访问 test-ipv6.com → 无 v6，仅 v4（海外锁定生效）。
   - 银行/AI 出口 IP 与启用前一致（exit-check 或 ipinfo.io）。
5. **回退**：恢复 Dnsmasq AAAA 过滤、关「IPv6 代理/解析」、重启插件，即回到当前状态。Xray 的 UseIPv4 可保留（它只影响出口选择，不影响是否使用 v6 直连）。

注意：QX 手机蜂窝/自设 DNS 场景与路由器相互独立，需单独用同样方法检查。fake-ip-filter 若为 rule/whitelist 语义，先按 [dns.md](dns.md) 转换，不能直接拼接。

## 不做什么

- 不给海外流量启用 v6——出口 IP 稳定性优先。
- 不在完成第 1 步（锁 v4）之前先开客户端 v6。
- 不因"v6 更新更先进"而启用：没有具体收益场景就选路线A。
