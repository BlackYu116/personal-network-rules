# 节点与订阅怎么选：先补短板，不急着再买年付

核查于2026-09-26。以下不是测速排行榜，没有获得这些服务在你的移动宽带/蜂窝下的付费实测，也不把营销承诺当成家宽或解锁证明。

## 现有组合已经能分工

- DMIT：自有、可管理的固定出口，适合已经验证可正常使用的固定账户场景。
- 现有仍有长期订阅的机场：用于日本Crypto出口、泛浏览、下载与备用。先从现有节点里挑出3–5个合格候选，而不是每次让整个机场竞速。
- 即将到期且不打算续订的机场：退出后只需在塔台禁用该来源，重新检查日本与全部节点组。不要让某个业务组留在已删除节点上。

节点名“日本”只是一条标签，服务器IP可能是入口；[出口体检](node-quality.md)才检查这次实际从哪里出来。运营商ASN不是家庭宽带身份验证，单个“IP纯净度分数”也不能代替目标服务的真实使用结果。

## 查到的可核验候选

| 服务 | 能核实什么 | 仍缺什么 |
|---|---|---|
| AmyTelecom | [官方公告](https://www.amytele.com/)说明协议已转AnyTLS；[官方频道](https://t.me/s/amytelecom_official)提供维护/故障信息 | 你所在地移动网络的高峰体验、每个节点实际出口、目标服务可用性 |
| Just My Socks | [官方知识库](https://justmysocks.net/members/knowledgebase.php)可查客户端与线路说明，是可进一步核验的候选 | 当前具体套餐的实测、是否补足现有线路、是否有你需要的出口；不宣称全部家宽 |
| Nexitally | [官方频道](https://t.me/s/Nexitally_Official)链接官方入口与FAQ | 缺乏足够近期的独立质量证据，也不能假定它与现有机场的上游故障完全独立 |

本次没有找到足以证明“某家必然比Amy更好、且适合你的移动网络”的证据，因此不建议基于推荐名单马上购买另一个长周期套餐。若现有组合实测后仍缺备用，可在核对官方最新售卖条件后选择最短可用周期试用。不要把未经官方确认的同名搜索网站作为付款入口。

测试目标应先明确：要补独立入口/运营商、晚高峰速度、日本实际出口，还是某项服务的可用性。测试时保存时间、接入网络、节点名、两站出口信息、失败情况和实际应用表现。QX测速快但目标服务打不开，该节点仍不适合该业务。

## 不必让所有节点同时工作

长期稳定的服务通常只需要少量明确分工的出口。金融/交易/AI保持手选固定；普通浏览可以选 `available` 主备，或 `url-latency-benchmark` 从合格候选优选；大下载放到另一个手选出口。按连接轮换或跨国家“自动最快”可能让同一账户的不同域名使用不同出口，不是默认优化方向。

QX可继续用来做：远程规则自动更新、按域名DNS、节点故障切换、HTTP连接诊断、节点出口检查。重写/MITM适用于明确的问题，并不会自动解锁付费权益或让服务忽略地区及账户条件。Apple News本次先不启用，也没有添加其他解锁脚本。
